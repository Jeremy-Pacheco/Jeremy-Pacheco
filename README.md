## About Me

I'm a **Full Stack Web Developer** with a degree in **Web Application Development (DAW)**, currently studying Computer Engineering.

I've done two internships at AlexVega: one with **React**, building a Minesweeper-style game with functional tests, and another with **Svelte**, Canvas and Three.js, where I also built a component for an internal SvelteKit library with unit and Playwright tests.

Most of what I build is JavaScript/TypeScript: React or Svelte on the frontend, Node.js and Express on the backend. I like taking an idea from a rough sketch to something people can actually use, which usually means a bit of everything: UI, APIs, database and tests.
